# breeathy-site

Public pages for the Breeathy test app, served with GitHub Pages at https://breeathy.reispace.com/.

- `/` — about the app
- `/privacy/` — privacy policy
- `/delete-account/` — how to delete an account
- `/support/` — contact

Plain HTML and CSS: no build step, no JavaScript, no external requests, no cookies. Pages are marked `noindex`.

Preview locally from this folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.
